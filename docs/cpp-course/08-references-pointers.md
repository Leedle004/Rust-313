# 第 8 课：引用，以及指针的谨慎入门

你将学会：用引用给已有变量起别名；弄清指针存的是地址。日常写函数参数时优先引用。本课**不**做 `new` / `delete`。

## 1. 引用：同一个东西的另一个名字

```cpp
int x = 10;
int& r = x;  // r 是 x 的引用
r = 20;      // x 也变成 20
```

`int&` 读作「int 的引用」。`r` 不是新盒子，是贴在 `x` 上的第二张标签。

规则：

- 声明引用时必须绑定到一个已存在的对象：`int& r = x;`
- 不能先写 `int& r;` 再到处找要绑谁
- 绑定之后不能改去绑另一个变量
- 改引用就是改原变量

完整示例：[`examples/08-reference.cpp`](examples/08-reference.cpp)

## 2. 函数参数用引用：才能改外面的值

第 5 课说过，默认传的是副本。要改调用方的变量，把参数写成引用：

```cpp
void add_one(int& n) {
    n += 1;
}

int x = 1;
add_one(x);  // x 变成 2
```

只读、又不想复制大对象（例如 `std::string`、`std::vector`）时，用 **`const` 引用**：

```cpp
void print_name(const std::string& name) {
    std::cout << name << "\n";
    // name += "!";  // 编译失败，这是只读的
}
```

口令：

- 要改它：`T&`
- 只读它：`const T&`（小的 `int`、`double` 直接按值传也行）
- 默认别用指针做参数，除非接口已经是指针

范围 for 里改元素：

```cpp
for (int& s : scores) {
    s += 1;
}
```

## 3. 指针：盒子里放的是地址

每个变量在内存里有地址。`&x` 表示「`x` 的地址」（这里的 `&` 不是引用声明，而是「取地址」）。

指针变量保存这个地址：

```cpp
int x = 10;
int* p = &x;   // p 指向 x
```

- `int*`：指向 `int` 的指针
- `*p`：顺着地址找到那个 `int`（解引用）
- `p` 本身是地址；`*p` 才是值

```cpp
std::cout << *p << "\n";  // 10
*p = 20;                  // x 变成 20
```

完整示例：[`examples/08-pointer.cpp`](examples/08-pointer.cpp)

空指针用 **`nullptr`**（不要写 `NULL`，不要写 `0` 当空指针）：

```cpp
int* p = nullptr;
```

对 `nullptr` 做 `*p` 是未定义行为，程序可能崩溃。用之前先判断：

```cpp
if (p != nullptr) {
    std::cout << *p << "\n";
}
```

## 4. 引用和指针怎么选（现在只要记住这些）

| | 引用 `int&` | 指针 `int*` |
| --- | --- | --- |
| 必须一开始就绑上对象 | 是 | 否，可以是 `nullptr` |
| 能改绑到别处 | 否 | 能（`p = &y;`） |
| 表示「可能没有」 | 不合适 | 可以用 `nullptr` |
| 函数参数（本课建议） | 优先 | 仅当必须表示空或对接旧接口 |

读别人的代码时你会看到指针。自己写小程序：能用引用就用引用；一串数据用 `std::vector`，不要自己 `new int[n]`。

下面这种代码本课禁止：

```cpp
int* p = new int(3);  // 不要
delete p;
```

手动申请内存要配对释放，漏了会泄漏，释放两次或用已释放的内存是未定义行为。标准库容器已经帮你管好内存。

## 5. 常见混淆

```cpp
int x = 1;
int* p = &x;
```

- `&x`：取地址
- `int& r = x;`：声明引用
- `*p`：解引用指针
- `int* p`：声明指针

同一符号在不同位置意思不同。看它是出现在**类型里**还是**表达式里**。

不要返回指向局部变量的指针或引用：

```cpp
int* bad() {
    int n = 1;
    return &n;  // n 在函数结束时销毁，地址作废
}
```

需要把值带出去：`return n;` 按值返回。

## 6. 本课要点

- 引用是别名；函数要用它来修改实参，或用 `const T&` 避免拷贝
- 指针保存地址；解引用用 `*p`；空指针是 `nullptr`
- 不要解引用空指针；不要 `new` / `delete`
- 能用引用就不用指针
