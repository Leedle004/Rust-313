# 第 1 课：环境、Hello World、编译和运行

你将学会：确认编译器可用、写一个会打印文字的小程序、把它编译成可执行文件、看懂最常见的报错。

聊天里的 Hello World 只是热身。这一课写成完整步骤，以后忘了可以回来查。

## 1. 源文件是什么

C++ 程序从一份文本开始。约定：

- 文件名用英文和短横线或下划线，例如 `hello.cpp`
- 扩展名是 `.cpp`
- 用任何文本编辑器写都可以（VS Code、记事本、Vim……），不要用 Word

程序有一个约定入口：叫做 `main` 的函数。操作系统启动你的程序时，从这里开始执行。

## 2. 第一个程序

完整文件在 [`examples/01-hello.cpp`](examples/01-hello.cpp)。自己新建 `hello.cpp`，完整敲一遍：

```cpp
#include <iostream>

int main() {
    std::cout << "你好，C++\n";
    return 0;
}
```

逐行含义：

| 代码 | 意思 |
| --- | --- |
| `#include <iostream>` | 引入标准输入输出库。没有它，就不能用 `std::cout`。 |
| `int main()` | 程序入口。`int` 表示这个函数结束时会给操作系统一个整数状态码。 |
| `{ ... }` | 一对花括号圈出 `main` 要做的事。 |
| `std::cout << "你好，C++\n";` | 把引号里的文字送到「标准输出」（通常是终端）。`\n` 是换行。 |
| `return 0;` | 告诉操作系统：正常结束。`0` 表示成功。 |
| 每条语句末尾的 `;` | C++ 用分号结束一条语句。漏了会报错。 |

`std::` 表示「标准库里的名字」。`cout` 是 character output 的缩写，可以把它想成「往屏幕上写」。

`<<` 在这里的意思是「把右边的东西送给左边的 `cout`」。以后你会看到可以连着写：

```cpp
std::cout << "姓名：" << "Ada" << "\n";
```

## 3. 编译

在终端里进入 `.cpp` 所在目录。

**g++（Linux、macOS 上的 GCC、Windows MinGW）：**

```bash
g++ -std=c++17 -Wall -Wextra hello.cpp -o hello
```

**clang++：**

```bash
clang++ -std=c++17 -Wall -Wextra hello.cpp -o hello
```

**MSVC（Visual Studio 开发者命令提示符）：**

```text
cl /std:c++17 /W4 /EHsc hello.cpp
```

编译成功时，g++ / clang++ 通常**什么都不印**，只是多出一个可执行文件。这是正常的。有输出反而多半是警告或错误。

`-o hello` 指定输出文件名。省略的话，g++ 往往会生成名为 `a.out` 的文件（Windows MinGW 则可能是 `a.exe`）。起个清楚的名字更省事。

## 4. 运行

Linux / macOS：

```bash
./hello
```

Windows：

```text
hello.exe
```

你应看到：

```text
你好，C++
```

## 5. 一次完整走查

假设当前目录里只有你刚写的 `hello.cpp`：

```text
hello.cpp          ← 你写的源文件（人可以读）
```

编译之后：

```text
hello.cpp          ← 仍然在
hello              ← 新生成的程序（机器可以跑）
```

改源文件之后，必须**重新编译**，再运行。只改文字却不编译，跑起来的还是旧程序。这是初学者最常迷惑的一点。

## 6. 常见报错（现在就该见一次）

故意写错，比以后遇到时慌张要好。

**漏分号**

```cpp
std::cout << "你好，C++\n"
```

编译器会抱怨 `expected ';' before ...` 一类的话。看报错里的行号，到那一行附近找缺失的 `;`。

**单词拼错**

```cpp
std::cout << "你好\n";  // 若写成 std::cot，编译会失败
```

C++ 认不出 `cot`。错误信息里常有 `did you mean 'cout'` 或 `not a member of 'std'`。

**忘记 `#include <iostream>`**

会提示 `cout` 未声明。缺了头文件，标准库的名字就不会出现。

**命令找不到 `g++`**

说明编译器没装好，或终端没找到它的路径。回到 [README](README.md) 的安装一节，不要改代码。

**`./hello: No such file or directory`**

要么没编译成功，要么你不在那个目录，要么 Windows 下应该运行 `hello.exe`。

报错请从**第一行**读。后面一连串往往是第一处错误引起的连锁反应。

## 7. 注释和多行输出

`//` 后面到行尾是给人看的，编译器忽略：

```cpp
// 这是一行注释
std::cout << "第一行\n";
std::cout << "第二行\n";
```

更完整的示例见 [`examples/01-multiline.cpp`](examples/01-multiline.cpp)。

也可用 `/* ... */` 包住一段注释，本课以 `//` 为主。

## 8. 本课要点

- 源文件 `.cpp` → 编译器 → 可执行文件 → 运行
- `main` 是入口；`std::cout` 负责打印
- 改代码后要重新编译
- 看报错的文件名和行号

## 练习

先自己做。答案在 [`solutions/`](solutions/)，文件名与题号对应。

**练习 1.** 写一个程序，连续打印三行：问候语、你的名字、你正在学的语言。编译并运行。

**练习 2.** 把练习 1 的程序另存后，故意删掉一行末尾的分号，编译一次，把终端里**第一行**报错原样记下来。然后改回去，确认又能编译。不用交「记下来的文字」，目的是让你真的读一次报错。

**练习 3.** 写一个程序，打印一个用 `std::cout` 拼出来的小信息卡，至少包含两个 `<<` 连用，例如姓名和城市印在同一行。完整可运行即可。
