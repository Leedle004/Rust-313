# 第 2 课：变量、类型、初始化、`cin`

你将学会：用名字保存数据、选对常用类型、给变量一个明确的初始值、从键盘读入内容。

## 1. 变量是一个有名字的盒子

程序运行时要记住一些值：年龄、价格、姓名。变量就是这块内存上的名字。

```cpp
int age = 18;
```

含义：

- `int`：类型，这里是整数
- `age`：名字，你自己起
- `=`：把右边的值放进左边的变量（初始化或赋值）
- `18`：初始值
- `;`：结束语句

名字规则：字母、数字、下划线；不能以数字开头；区分大小写；不要用 C++ 关键字（例如 `int`、`return`）。初学建议用英文小写加下划线：`user_name`、`total_score`。

## 2. 先认识这几种类型

| 类型 | 存什么 | 例子 |
| --- | --- | --- |
| `int` | 整数 | `42`、`-3` |
| `double` | 小数（带小数点的数） | `3.14`、`-0.5` |
| `char` | 单个字符 | `'A'`、`'中'` 在有的环境下占不止一字节，本课只用英文或数字字符，例如 `'A'`、`'7'` |
| `bool` | 真或假 | `true`、`false` |
| `std::string` | 一串文字 | `"hello"`（需要 `#include <string>`） |

`char` 用**单引号**，`std::string` 用**双引号**。不要混。

完整示例：[`examples/02-types.cpp`](examples/02-types.cpp)

```cpp
#include <iostream>
#include <string>

int main() {
    int year = 2026;
    double price = 19.9;
    char grade = 'A';
    bool passed = true;
    std::string name = "Ada";

    std::cout << "年份：" << year << "\n";
    std::cout << "价格：" << price << "\n";
    std::cout << "等级：" << grade << "\n";
    std::cout << "通过：" << passed << "\n";  // true 会印成 1，false 成 0
    std::cout << "姓名：" << name << "\n";
    return 0;
}
```

`bool` 打印出来是 `1` 或 `0`，这是正常的。后面用 `if` 时会按真假来用，不必先纠结显示。

整数和小数不要随便混着「看起来能算」。`int` 除法会丢掉小数部分，第 3 课会专门练。需要小数时用 `double`。

## 3. 初始化：先给值，再使用

C++ 允许声明变量却不给值：

```cpp
int score;
```

此时 `score` 里是**不确定的垃圾值**。拿去打印或计算，程序可能每次结果都不同，这叫未定义行为的一种常见入口。初学规则：

**声明时就给值。**

三种常见写法，本课都认，优先前两种：

```cpp
int a = 0;      // 很直观
int b{0};       // 列表初始化，也能防止某些危险的缩窄转换
int c(0);       // 也可以，本课少用
```

常量用 `const`，一旦定下就不能改：

```cpp
const double pi = 3.14159;
```

试图改 `pi` 会编译失败。不会变的量就写成 `const`，既是给自己看的说明，也是给编译器的约束。

## 4. 赋值会覆盖旧值

```cpp
int n = 1;
n = 2;       // 现在 n 是 2
n = n + 1;   // 读出 2，加 1，写回 n，结果是 3
```

`=` 不是数学里的「等于」。它是「算右边，放进左边」。比较两个值是否相等要用 `==`，第 3 课再讲。

## 5. 从键盘读入：`std::cin`

`cout` 是输出，`cin` 是输入（character input）。完整示例：[`examples/02-cin.cpp`](examples/02-cin.cpp)

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    int age = 0;

    std::cout << "请输入姓名：";
    std::cin >> name;

    std::cout << "请输入年龄：";
    std::cin >> age;

    std::cout << name << "，" << age << " 岁。\n";
    return 0;
}
```

`>>` 的方向和 `<<` 相反：从 `cin` 取出内容，放进右边的变量。

注意：

- `std::cin >> name` 读到**空格就会停**。输入 `Ada Lovelace` 时，`name` 往往只有 `Ada`。整行文本放到第 7 课用 `std::getline`。
- 先打印提示，再读入，用户才知道该打什么。
- 如果输入的不是数字（年龄栏打了 `abc`），`age` 可能保持旧值，后面的读入也会乱。本课先保证输入格式正确；第 10 课再做更稳妥的检查。

运行时在终端里输入，每项后面按回车。

## 6. 类型要匹配你的数据

| 你想存 | 用 |
| --- | --- |
| 人数、计数、年份 | `int` |
| 身高、价格、温度 | `double` |
| 是/否 | `bool` |
| 姓名、一句话 | `std::string` |
| 单个字母等级 | `char` 或直接用 `std::string` |

拿不准时，文本用 `std::string`，需要小数用 `double`。不要用 `int` 存「学号必须前导零」这类编码，那种是文本。

## 7. 本课要点

- 变量 = 类型 + 名字 + 初始值
- 常用：`int`、`double`、`bool`、`char`、`std::string`
- 不要使用未初始化的变量
- `std::cin >> x` 从键盘读入；空格会截断字符串
