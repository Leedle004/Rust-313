# 第 3 课：运算符与表达式

你将学会：用加减乘除和比较写出表达式，搞清楚整数除法、取余，以及 `==` 和 `=` 的区别。

表达式就是「能算出一个值的代码」，例如 `3 + 4`、`age >= 18`。

## 1. 算术运算

| 符号 | 含义 | 例子（`int`） |
| --- | --- | --- |
| `+` | 加 | `3 + 2` → `5` |
| `-` | 减 | `3 - 2` → `1` |
| `*` | 乘 | `3 * 2` → `6` |
| `/` | 除 | 见下一节 |
| `%` | 取余（整数） | `7 % 3` → `1` |

完整示例：[`examples/03-operators.cpp`](examples/03-operators.cpp)

可以用括号改变顺序，规则与小学算术相同：先乘除后加减，括号最优先。

```cpp
int x = 2 + 3 * 4;      // 14，不是 20
int y = (2 + 3) * 4;    // 20
```

复合赋值（在原变量上改）：

```cpp
int n = 10;
n += 3;   // 等同 n = n + 3，现在 13
n -= 1;   // 12
n *= 2;   // 24
n /= 3;   // 8
n %= 5;   // 3
```

`++n` / `n++` 表示加一。本课建议写 `n += 1` 或 `++n`，先不要在同一行里混用 `n++` 和别的运算。

## 2. 整数除法会丢掉小数

这是 C++ 里最容易踩的坑之一：

```cpp
int a = 7;
int b = 2;
std::cout << a / b << "\n";        // 3，不是 3.5
```

两个 `int` 相除，结果仍是 `int`，小数部分直接丢掉（向零截断）。

需要小数时，让其中一边是 `double`：

```cpp
double mean = 7 / 2;          // 仍是 3.0，因为 7 和 2 都是 int，先算成 3 再放进 double
double mean_ok = 7.0 / 2;     // 3.5
double mean_ok2 = static_cast<double>(a) / b;  // 把 a 当成 double 再除
```

`static_cast<double>(a)` 的意思是「临时把 `a` 看成 `double`」。比在心里默默改类型更清楚。

`%` 只能用于整数。`7 % 2` 是 `1`（7 除以 2 余 1）。常用来判断奇偶：`n % 2 == 0` 是偶数。

除数不能是 0。整数除以 0 是未定义行为，程序可能崩溃。做除法前保证分母不是 0。

## 3. 比较：得到 `bool`

| 符号 | 含义 |
| --- | --- |
| `==` | 相等 |
| `!=` | 不相等 |
| `<` `<=` `>` `>=` | 小于、小于等于、大于、大于等于 |

```cpp
int age = 20;
bool adult = (age >= 18);  // true
```

**`=` 是赋值，`==` 是比较。** 写成 `if (age = 18)` 会先把 `age` 改成 18，再把 18 当成条件（非 0 即真）。带 `-Wall` 编译时通常会警告。比较一律用 `==`。

浮点数（`double`）用 `==` 比较常常不可靠，因为小数在二进制里可能是近似值。本课比较小数时用「差距是否很小」，或干脆比较整数。练习里避免 `double == double`。

## 4. 逻辑运算

| 符号 | 含义 | 例子 |
| --- | --- | --- |
| `&&` | 并且（两边都真才真） | `age >= 18 && has_id` |
| `\|\|` | 或者（有一边真就真） | `n < 0 \|\| n > 100` |
| `!` | 取反 | `!passed` |

```cpp
int score = 85;
bool ok = (score >= 60 && score <= 100);
```

C++ 的 `&&` / `||` 会短路：左边已经能决定结果时，右边不算。例如 `n != 0 && 10 / n > 1`，当 `n == 0` 时不会去做除法。写条件时可以把「先排除危险情况」放在左边。

## 5. 字符串也能比较

`std::string` 支持 `==`、`!=`、`<` 等。`<` 按字典序（大致上是字母表顺序），本课主要用 `==` 判断用户输入是否等于某个词：

```cpp
std::string cmd;
std::cin >> cmd;
bool quit = (cmd == "quit");
```

## 6. 本课要点

- `+ - * / %` 与括号
- `int / int` 丢掉小数；要小数就让一边是 `double`
- `==` 比较，`=` 赋值
- `&&` `||` `!` 组合条件；注意除以 0
