# 参考答案

先自己做课文里的练习，再打开这里的文件。

命名：`课号-ex题号.cpp`。例如第 4 课第 2 题是 `04-ex2.cpp`。

第 10 课按步骤拆开：

- `10-step1.cpp` 菜单循环
- `10-step2.cpp` 添加与列出
- `10-step3.cpp` 平均分
- `10-step4.cpp` 最高分
- `10-gradebook.cpp` 完整成绩册

编译某一份答案：

```bash
g++ -std=c++17 -Wall -Wextra 02-ex1.cpp -o ex
./ex
```

答案只是一种写对的办法。你的变量名、提示文字可以不同，行为符合题目即可。
