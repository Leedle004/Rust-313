# 星际突围

一款零依赖的浏览器 Canvas 射击游戏。玩家驾驶战机在星际战场中移动、瞄准并射击敌机，随着分数和时间提升会进入更高波次。

## 运行

直接打开 `index.html`，或在仓库根目录启动一个静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 操作

- `WASD` / 方向键：移动
- 鼠标：瞄准
- 鼠标点击 / 空格：射击
- `P`：暂停 / 继续
- `R`：重新开始

## 功能

- Canvas 实时渲染与游戏循环
- 多类型敌人、波次升级和碰撞检测
- 分数、生命值、最佳分和状态 HUD
- 火力强化、修复道具和爆炸粒子反馈
- 无构建依赖，适合静态部署
