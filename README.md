# 20MB Data Runner

一款无需安装依赖的轻量级浏览器小游戏。所有画面都由 Canvas 程序化绘制，没有外部图片、音频或字体资源，仓库体积远低于 20MB。

## 玩法

- 使用 `WASD` 或方向键移动飞船。
- 收集蓝色/黄色数据碎片获得分数。
- 躲开红色病毒；碰到病毒会损失生命。
- 绿色补丁会提供短暂护盾，护盾期间撞到病毒可以摧毁它们。
- 在 90 秒内达到 2000 分即可完成“20MB 压缩目标”。
- `P` 暂停/继续，`R` 重新开始。

## 运行

直接用浏览器打开 `index.html` 即可。

如果想通过本地静态服务器运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 文件结构

- `index.html`：游戏页面和 HUD。
- `styles.css`：响应式界面和视觉样式。
- `game.js`：Canvas 游戏循环、输入、碰撞、计分与胜负逻辑。
