# 星际防线

一款使用原生 HTML、CSS 和 JavaScript Canvas 开发的轻量射击游戏。玩家驾驶战机防守星际基地，击落不断增强的敌机，躲避撞击并挑战高分。

## 运行方式

直接在浏览器中打开 `index.html` 即可游玩。

也可以使用任意静态服务器预览，例如：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 操作说明

- `W` `A` `S` `D` 或方向键：移动战机
- `Space`：发射能量弹
- `P`：暂停 / 继续
- `R`：重新开始
- 鼠标或触控：移动到指针位置，点击射击

## 游戏特性

- Canvas 实时渲染星空、玩家、敌机、子弹和爆炸粒子
- 分数、生命和波次 HUD
- 随分数提升的敌人生成速度与敌机类型
- 键盘、鼠标和触控输入支持
- 暂停、重开和游戏结束状态
