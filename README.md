# Rust-313

一个无需构建步骤的浏览器 Canvas 射击游戏：**星际防线**。

## 运行方式

直接用浏览器打开 `index.html`，或在仓库目录启动任意静态文件服务器。

例如：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 操作说明

- `A` / `D` 或 `←` / `→`：左右移动
- `空格`：射击
- `P`：暂停或继续
- `Enter`：开始或重新开始

## 玩法

击落来袭敌机获得分数；敌机会随时间加速并提高出现频率。漏掉敌机或被撞击会损失生命，生命耗尽后游戏结束。最高分会保存在浏览器本地。
