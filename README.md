# 星尘快递（Stardust Courier）

一款面向 **20MB 发布包预算** 的 HTML5 Canvas 太空动作小游戏。玩家驾驶快递飞船在碎星带中收集星尘晶体、送回中央母舰，同时躲避并击毁逐步增强的敌方无人机。

## 玩法

- **移动**：WASD 或方向键
- **瞄准**：鼠标移动
- **射击**：鼠标点击或空格
- **暂停 / 继续**：P
- **重新开始**：R 或点击页面按钮
- **移动端**：左下虚拟摇杆移动，右下按钮射击

## 运行

这是一个无构建步骤的静态网页游戏，直接打开 `index.html` 即可运行。

也可以使用本地静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 20MB 包体策略

当前游戏没有引入外部图片、音频或框架依赖，视觉效果、粒子和音效均在运行时程序化生成。因此仓库体积远低于 20MB，后续可以在该预算内继续加入手绘贴图、关卡数据或背景音乐。
